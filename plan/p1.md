Implement a dedicated **System Design Markdown Reader** that renders MD files in a clean, Notion-like reading experience optimized for both mobile and webview environments.

### Core Requirements

* Use the MD file as the single source of truth.
* Render all standard Markdown elements correctly:

  * H1–H6 headings
  * Paragraphs
  * Bold, italic, strikethrough
  * Ordered and unordered lists
  * Checklists
  * Blockquotes
  * Tables
  * Horizontal dividers
  * Inline code
  * Code blocks with syntax highlighting
  * Links
  * Callouts/admonitions
  * Nested content structures

### Media Support

* Support single and multiple images anywhere in the document.
* Images should be responsive, lazy-loaded, zoomable, and optimized for mobile.
* Support image captions when available.
* Handle diagrams, architecture screenshots, and embedded visual assets gracefully.

### Reader Experience

* Create a Notion-inspired layout focused on readability.
* Add proper typography, spacing, and content hierarchy.
* Generate a sticky table of contents from headings when available.
* Support deep-linking to sections.
* Add smooth scrolling between sections.
* Ensure long documents remain performant.

### Metadata

If metadata exists, display it above the document:

* Title
* Category (LLD/HLD)
* Reading time
* Difficulty
* Last updated
* Tags

### Mobile-First Requirements

* Mobile experience is the highest priority.
* All tables must be horizontally scrollable.
* Code blocks must support horizontal scrolling.
* Images should never overflow the viewport.
* Maintain excellent readability on small screens and webviews.
* Ensure touch-friendly spacing, navigation, and interactions.

### Robustness

The renderer must handle different MD file structures and authoring styles without breaking:

* Missing sections
* Additional custom sections
* Multiple images
* Large code snippets
* Deep heading hierarchies
* Long technical documents
* Future Markdown extensions
